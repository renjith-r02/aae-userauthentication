## 🚀 **HOW TO RUN THE APPLICATION**

### Step 1: Start Dependencies
```bash
cd /Users/renjithr/Downloads/Renjiths_Programming/GITHub/AuthService2
docker-compose up -d
```

### Step 2: Verify PostgreSQL and Redis
```bash
docker ps
# Should show both containers running
```

### Step 3: Build the Application
```bash
mvn clean install
```

### Step 4: Run the Application
```bash
mvn spring-boot:run
```

### Step 5: Verify Application is Running
```bash
# Check health
curl http://localhost:8080/actuator/health

# Should return:
# {"status":"UP","components":[{"name":"database","status":"UP",...},{"name":"redis","status":"UP",...}]}
```

### Step 6: Test Registration
```bash
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com",
    "password": "SecurePass@123"
  }'
```

### Step 7: Test Login
```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john.doe@example.com",
    "password": "SecurePass@123"
  }'
```

### Step 8: Test Protected Endpoint
```bash
# Use the accessToken from login response
curl -X GET http://localhost:8080/api/v1/auth/me \
  -H "Authorization: Bearer <your-access-token>"
```

### Step 9: Run Tests
```bash
# Run all tests
mvn test

# Run integration tests only
mvn verify

# Generate coverage report
mvn clean verify jacoco:report
# Report available at: target/site/jacoco/index.html
```

### Step 10: Run Load Tests
```bash
jmeter -n -t jmeter/AuthService-LoadTest.jmx -l results.jtl -e -o results/
```
